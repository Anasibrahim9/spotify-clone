# Spotify Clone 🎵

A responsive **Spotify-inspired music player** built with HTML, CSS, and JavaScript. It recreates the Spotify-style interface with a dynamic music library, playlist cards, and functional audio controls.

## Features

* Responsive Spotify-inspired UI
* Dynamic song library loaded from JSON
* Playlist cards with album artwork
* Play / pause functionality
* Previous / next track controls
* Seek bar with current and total time
* Volume control and mute/unmute
* Responsive mobile sidebar
* Interactive hover effects

## Tech Stack

* HTML5
* CSS3
* JavaScript
* HTML5 Audio API
* JSON
* Fetch API
* Flexbox
